# A crawler obeys exactly ONE group: the most specific User-agent that matches
# it, and nothing from any other group. So every named bot below has to repeat
# the Disallow list — a group containing only "Allow: /" does not inherit the
# restrictions from "User-agent: *", it replaces them. The named AI groups here
# used to be exactly that, which permitted them to crawl dashboards and other
# people's scan reports.
